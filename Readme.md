# Конвертер валют (CurrencyConverter)

Простое консольное приложение на языке Python для перевода российских рублей (RUB) в иностранные валюты (USD, EUR, CNY) по фиксированному курсу.

## Требования
* Операционная система: Windows / Linux / macOS
* Установленный интерпретатор Python версии 3.8 или выше
* Дополнительные библиотеки не требуются (используются только стандартные функции Python)

## Как запустить
1. Откройте терминал или командную строку.
2. Перейдите в папку с программой (`version_0.1.1`).
3. Выполните команду:
   ```bash
   python main.py
   ```
