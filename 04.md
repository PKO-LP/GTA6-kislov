ОПИСАНИЕ ПРОГРАММЫ
«Конвертер валют»

1. Общие сведения
Программа написана на языке Python 3 без использования сторонних библиотек. Работа осуществляется в режиме диалога с пользователем в консоли (терминале).

2. Логика работы (алгоритм)
1. При запуске инициализируется словарь rates с курсами валют (USD = 90.0, EUR = 98.5, CNY = 12.4).
2. Запускается бесконечный цикл while True, который выводит на экран меню из 4 пунктов.
3. С помощью функции input() считывается выбор пользователя.
4. Если введено "0", цикл прерывается оператором break и программа завершается.
5. Если введено "1", "2" или "3", программа запрашивает сумму в рублях, преобразует строку в число с плавающей точкой float() внутри блока try-except.
6. Проверяется условие rub <= 0. Если число отрицательное или равно нулю, выводится предупреждение и цикл начинается заново.
7. Выполняется деление суммы в рублях на курс выбранной валюты, результат округляется функцией round(result, 2) и выводится на экран.
