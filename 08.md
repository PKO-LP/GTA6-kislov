РУКОВОДСТВО ПРОГРАММИСТА
программы «Конвертер валют» v0.1.1

1. Настройка среды
Для работы программы требуется установленный интерпретатор Python 3.8 и выше. Установка виртуального окружения (venv) и дополнительных пакетов через pip не требуется.

2. Модификация курсов валют
Курсы валют заданы в начале файла main.py в словаре rates:
rates = {
    "USD": 90.0,
    "EUR": 98.5,
    "CNY": 12.4
}
Для обновления курсов необходимо открыть файл main.py в любом текстовом редакторе или IDE и изменить числовые значения на актуальные.
