СПЕЦИФИКАЦИЯ ПРОГРАММЫ
«Конвертер валют» (версия 0.1.1)

1. Состав программного продукта:
- main.py — основной исполняемый модуль программы на языке Python (размер ~1.2 КБ).
- README.md — файл с кратким описанием и инструкцией по запуску.

2. Используемые структуры данных:
- rates (dict) — словарь с фиксированными курсами валют по отношению к рублю.
- choice (str) — переменная для хранения выбранного пользователем пункта меню.
- rub (float) — переменная для хранения исходной суммы в рублях.
- result (float) — переменная для хранения итогового результата конвертации.
